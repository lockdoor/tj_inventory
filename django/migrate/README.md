# Migration Context (`django/migrate`)

This directory is responsible for transforming raw business Excel files into structured JSON data that can be ingested by our Django application.

> [!WARNING]
> **Sensitive Data Notice**: The `django/migrate/data` directory is intentionally excluded from the repository. It contains real business records (Excel files) and sensitive configurations. You must manually create this folder and provide the necessary files locally.

## 1. Directory Structure

```text
django/migrate/
├── Makefile                # Contains the `make excel_migration` command
├── README.md               # This documentation
├── scripts/
│   └── excel_migration.py  # The main processor script
└── data/                   # (Not in version control) Put your files here
    ├── migration_config.json # You must create this
    ├── example1.xlsx         # Raw excel files
    ├── example2.xlsx           
    └── stock_migration.json  # Auto-generated by the python script
```

## 2. Requirements

To run the migration process, you need to create the `django/migrate/data/` folder and provide two types of files:

### A. Raw Excel Files
Place your original inventory Excel tracking files inside the `data` directory.

### B. Configuration File (`migration_config.json`)
You must create `django/migrate/data/migration_config.json` to map the Excel files and sheets to the system SKUs.

**Mockup of `migration_config.json`:**
```json
{
  "example_data_group": {
    "filename": "../data/example1.xlsx",
    "warehouse": "TG001",
    "items": {
      "item_key_1": {
        "sheet": "Sheet1_Name",
        "sku": "00-1111-11",
        "name": "Sample Item Name",
        "name2": "Sample English Name",
        "unit": "Pcs"
      },
      "item_key_2": {
        "sheet": "Sheet2_Name",
        "sku": "00-1111-12",
        "name": "Another Item Name",
        "name2": "Another English Name",
        "unit": "Box"
      }
    }
  }
}
```

## 3. How to Use

### Step 1: Generate the Migration JSON
Once your files are placed in the `data/` directory, navigate to the `django/migrate` directory and run:

```bash
make excel_migration
```

This command executes `scripts/excel_migration.py`, which will:
1. Read `migration_config.json`.
2. Parse the specified Excel files.
3. Clean dates and generate standard Lot Numbers.
4. Output `django/migrate/data/stock_migration.json` containing the normalized movement records.

### Step 2: Seed the Django Database
Navigate to your Django `srcs` directory (`django/srcs/`) and use the management commands to import the processed data into the live system:

```bash
# 1. Seed the item catalog (Uses migration_config.json to setup names, SKUs, and units)
python manage.py seed_items_real

# 2. Seed the inventory movements and stock (Uses stock_migration.json)
python manage.py seed_stock_migration
```
